# VetAgenda-CaS2026

Sistema web de gestión de citas veterinarias — Trabajo final de Laboratorio de Calidad de Software, UNSA 2026.

## Objetivo

Desarrollar una aplicación web para gestionar la reserva, la atención y los cambios de citas de una clínica veterinaria, aplicando las nueve guías del curso al mismo producto.

## Alcance previsto

- Usuarios con roles de cliente, recepcionista, veterinario y administrador.
- Registro de mascotas y consulta de disponibilidad.
- Reserva, reprogramación y cancelación de citas con validaciones de horario.
- Confirmación de llegada, registro de atención e historial por mascota.
- Control de inasistencias y reportes consolidados de citas.
- Persistencia de datos y control de acceso según el rol.

## Tecnologías propuestas

Java 21, Spring Boot, Maven, Thymeleaf, Bootstrap y PostgreSQL.

## Estado del proyecto

Repositorio inicial de trabajo. El alcance y las tecnologías descritos corresponden a la propuesta del primer entregable; su implementación y verificación se documentarán durante el desarrollo.
