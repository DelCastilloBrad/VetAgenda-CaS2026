# G01 · Requerimientos

**Producto:** VetAgenda 0.1.0 · **Estado:** avance con pendientes de cierre · [Seguimiento G01](https://github.com/DelCastilloBrad/VetAgenda-CaS2026/issues/23)

## Objetivo

Definir una especificación de requisitos verificable para los tres procesos de VetAgenda: reserva y agenda, llegada y atención, consulta y administración.

## Herramienta, versión y requisitos vinculados

GitHub Issues y Markdown. La versión del producto es 0.1.0; la ERS usa IEEE 830 como referencia académica de estructura.

RF-01 a RF-12, RNF-01 a RNF-06 y reglas de negocio de agenda y acceso.

## Procedimiento realizado

Se definió una línea base técnica a partir del alcance del primer entregable. Se registraron cuatro roles (CLIENTE, RECEPCION, VETERINARIO y ADMIN), criterios de aceptación y exclusiones. El documento se relacionó con Issues y con la trazabilidad del código.

## Resultados obtenidos

Hay 12 RF y 6 RNF. La ERS distingue reglas implementadas de verificaciones pendientes. Los correos se simulan en el log; pagos, facturación e inventario quedan fuera del alcance.

## Análisis

La cantidad de requisitos supera el mínimo del trabajo, pero eso no acredita elicitación ni validación. No hay evidencia de entrevistas o de aceptación por una clínica. Los umbrales de usabilidad y recuperación necesitan mediciones propias.

## Conclusiones

La ERS proporciona una base para el diseño, las pruebas y la trazabilidad del producto.
