# G05 · Gestión de configuración

**Producto:** VetAgenda 0.1.0 · **Estado:** avance con pendientes de cierre · [Seguimiento G05](https://github.com/DelCastilloBrad/VetAgenda-CaS2026/issues/27)

## Objetivo

Reconstruir versiones del producto, controlar cambios e identificar qué versión produjo cada evidencia.

## Herramienta, versión y requisitos vinculados

Apache Subversion 1.14.3 reportado en el equipo del usuario; Git y GitHub para publicación y comparación. GitHub no sustituye el ejercicio SVN exigido.

Requisitos, diseño, código, migraciones, scripts, pruebas y documentación; etiqueta final v1.0.0.

## Procedimiento realizado

El informe de avance revisado registra un ejercicio SVN con ocho revisiones, rama, conflicto y recuperación portable. El repositorio GitHub conserva código y pruebas. Los artefactos SVN pertenecen al paquete externo descrito en el informe y todavía no se localizan en este repositorio.

## Resultados obtenidos

Actividad SVN reportada en el informe; falta incorporar sus originales a una ubicación versionada verificable. La etiqueta final y su equivalencia con el paquete no se consideran acreditadas.

## Análisis

Un commit Git no equivale a una revisión SVN del ejercicio. Un historial capturado no sustituye el respaldo portable ni la recuperación verificable. Cada reporte debe identificar revisión, versión, fecha y alcance, sin atribuirle automáticamente el hash de otro ejecutable.

## Conclusiones

El informe documenta el ejercicio SVN y GitHub conserva la publicación del código y las pruebas.
